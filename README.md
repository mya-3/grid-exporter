# Grid Exporter

グリッドの選択と出力を行うWebツールです。

<img width="540" alt="grid_exporter" src="https://github.com/user-attachments/assets/7582d3dc-94e9-415a-8060-0cb84d95590e" />

## 主な機能

- グリッドの直感的な編集
  - クリック・ドラッグによる選択
  - 選択順の可視化
- 複数形式での出力
  - C++プログラムへの埋め込み形式・標準入出力形式
  - 1次元換算座標・2次元座標・グリッド文字列

## 使い方

1. 行数・列数を指定してグリッドを作成します。
1. グリッドをクリックまたはドラッグして編集します。
1. コピーボタンをクリックして対応する出力をクリップボードにコピーします。

## その他

- 元に戻す/やり直し は `Ctrl+Z`/`Ctrl+Y` でも操作できます。
- 選択データを外部へ送信する処理は行っていません。
  全ての処理はブラウザ内で完結します。
