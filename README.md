# Grid Exporter

グリッドの選択と出力を行うWebツールです。

<img width="530" alt="grid_exporter_language_pulldown" src="https://github.com/user-attachments/assets/6d65bf1b-95f1-4e58-919e-5e7ec66c29a1" />

## 主な機能

- グリッドの直感的な編集
  - クリック・ドラッグによる選択
  - 選択順の可視化
- レイヤーの追加削除
  - 他のレイヤーでの選択は薄い灰色で表示
- 複数形式での出力
  - プログラムへの埋め込み形式 / 標準入力形式
    - C++ / Python / Rust
  - 1次元換算座標 / 2次元座標 / グリッド文字列

## 使い方

1. 行数・列数を指定してグリッドを作成します。
1. グリッドをクリックまたはドラッグして編集します。
1. コピーボタンをクリックして対応する出力をクリップボードにコピーします。

## キーボードショートカット

- 元に戻す：`Ctrl + Z`
- やり直し：`Ctrl + Y`
- レイヤーを追加：`Alt + A`
- 現在のレイヤーを削除：`Alt + D`
- レイヤーの切り替え：`[` `]`

## その他

- 選択データを外部へ送信する処理は行っていません。  
  全ての処理はブラウザ内で完結します。
